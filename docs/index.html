Cardputer ADV — Node

ESP32-S3 · CAP CC1101

DF rover with its own screen + keyboard. Needs the M5Stack Cap CC1101 installed.

Open in Chrome or Edge to flash.
  1. Connect the board over USB.
  2. Click the Flash button for that device.
  3. Pick the serial port (hold BOOT/G0 while plugging in if it doesn't appear).
  4. Let it erase + install, then reconnect to the Scarecrow Wi-Fi.
Receive-only. No transmit path in any Scarecrow firmware.
