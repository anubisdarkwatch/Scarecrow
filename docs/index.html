SCARECROW

Receive-only sub-GHz sensor · Evil Crow RF V2 · v0.2.0

This firmware has no transmit path. The two CC1101 radios are only ever placed in RX/IDLE. WiFi is used solely to serve a read-only dashboard.
Use Chrome, Edge, or Opera on desktop (Web Serial). Serial access was blocked — reload and allow it.

Flash

  1. Open this page in Chrome / Edge / Opera on a desktop.
  2. Plug the Evil Crow RF V2 in by USB.
  3. Click Flash via browser, pick the serial port, confirm erase.
  4. When done: join WiFi Scarecrow / watchonly → browse to http://192.168.4.1.

Can't enter download mode? Hold BOOT, tap EN/RST, release BOOT, then flash.

Prefer esptool?

Single merged image, flash at offset 0:

esptool.py -c esp32 -p <PORT> write_flash 0x0 scarecrow.merged.bin

The separate parts are also here if you want them: scarecrow.bootloader.bin@0x1000, scarecrow.partitions.bin@0x8000, boot_app0.bin@0xe000, scarecrow.app.bin@0x10000.

Built from source for ESP32-PICO-D4, DIO, 4MB, huge_app partition. API-verified against the dual-module ELECHOUSE fork; not yet hardware-tested on a live V2.
